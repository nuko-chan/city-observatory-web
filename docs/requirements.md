# City Observatory - 要件定義書

[← README に戻る](../README.md)

## 1. プロジェクト概要

### 1.1 プロジェクト名

**City Observatory（シティ・オブザバトリー）**

### 1.2 コンセプト

都市の"いま"を観測するダッシュボード - 日本の主要都市の天気・大気質を 1 画面で可視化する Web アプリケーション

### 1.3 対象地域と前提

- **対象地域**: 日本（初期は東京を基準）
- **言語/単位**: 日本語 UI、メートル法（℃、m/s、mm）
- **タイムゾーン**: `Asia/Tokyo`
- **既定都市**: Tokyo

### 1.4 目的・背景

#### ビジネス目的

- 転職活動用ポートフォリオの作成
- フロントエンド開発スキルの証明

#### 制約条件

- フロントエンドのみで完結（バックエンド不要）
- 完全非商用（ポートフォリオ用途）
- 無料デプロイ（Vercel 無料枠）
- 無料 API（Open-Meteo 等のキー不要 API を優先使用）

## 3. 機能要件

### 3.1 コア機能（実装済み）

#### F1. 都市切り替え

- 固定 6 都市のボタン切り替え（東京/大阪/名古屋/札幌/福岡/那覇）
- 都市検索機能（Geocoding API 連携）
- 既定都市は Tokyo

#### F2. 地図表示機能

- インタラクティブな地図表示（MapLibre GL JS、ズーム・パン対応）
- 都市マーカーの表示と中心座標への移動
- レイヤー切替（降水量オーバーレイ）
- クレジット表記（OSM + MapTiler、Free プランロゴ）
- レスポンシブ対応

#### F3. 天気データ表示機能

- 現在の気象データ表示（気温/湿度/風速/降水確率）
- 24 時間予報の時系列チャート
- 7 日間予報の時系列チャート
- 天気コードによるアイコン・ラベル表示（WMO 準拠）
- 風向き・風速ビジュアライザー
- 日の出/日の入り可視化（太陽軌道表示）
- UV 指数カード

#### F4. 大気質（AQ）データ表示機能

- PM2.5/PM10/NO2/O3 濃度の表示
- PM2.5 ベースの簡易ラベル分類（良好/普通/注意/警戒）
- 24 時間/5 日間の AQ 予報チャート

#### F5. 都市比較機能

- 2 都市の主要指標を横並び比較
- URL 共有機能（比較状態をクエリパラメータで保持）

#### F6. 派生指標

- 快適度スコアの算出（気温・湿度・風・降水・AQ から算出）
- 外出リスクレベルの算出
- ベストタイムスロットの提案

### 3.2 UX 機能（一部実装済み）

- スケルトンローディング
- エラー時のフォールバック表示
- キャッシュ機能（TanStack Query、15 分 stale）
- URL クエリパラメータでの状態保持（nuqs）
- ダークモード（next-themes）

---

## 4. 非機能要件

### 4.1 パフォーマンス目標

- Lighthouse Performance スコア 90+
- FCP < 1.5 秒、LCP < 2.5 秒、CLS < 0.1

### 4.2 互換性

- モダンブラウザ対応（Chrome/Firefox/Safari/Edge 最新版）
- レスポンシブデザイン（SP/Tablet/PC）
- ダークモード対応

### 4.3 品質要件

- TypeScript strict モード
- ESLint/Prettier + Husky/lint-staged による自動チェック
- Zod による実行時バリデーション
- 責務分離（UI/Model/Domain、FSD 構成）
- `useContext` 禁止（jotai を使用）
- `type` のみ使用（`interface` 禁止）
- `undefined` を `null` より優先

## 5. 画面構成

### 画面 A: ダッシュボード（`app/page.tsx`）

メインページ。選択都市の天気・大気質・地図を 1 画面で表示。

- PC: 2 カラム（左: 情報パネル、右: 地図）
- SP: 縦積み

### 画面 B: 比較モード（`app/compare/page.tsx`）

2 都市の主要指標を横並び比較。

### 画面 C: About（`app/about/page.tsx`）

プロフィール・リンク集。

## 6. 外部 API

| API                    | 用途         | 認証 | レート制限                |
| ---------------------- | ------------ | ---- | ------------------------- |
| Open-Meteo Geocoding   | 都市検索     | 不要 | 過剰利用禁止              |
| Open-Meteo Weather     | 天気予報     | 不要 | 商用は有料                |
| Open-Meteo Air Quality | 大気質予報   | 不要 | 過剰利用禁止              |
| MapTiler Vector Tiles  | 地図タイル   | 必須 | 100,000 タイル/月（Free） |
| OpenWeatherMap Tiles   | 降水レイヤー | 必須 | プラン依存                |

---

## 7. ライセンス・規約遵守

- **Open-Meteo**: 非商用利用、クレジット表記
- **MapTiler**: クレジット表記必須、Free プランはロゴ表示必須
- **OpenStreetMap**: クレジット表記必須、リンク付き
- タイルの大量ダウンロード・プリフェッチ禁止

---

## 8. コスト制約

- 全ての API は無料枠内で利用
- MapTiler: Free プラン（100,000 タイル/月）
- Vercel: Free プラン（100GB 帯域/月）
